# >_REPOSITORY

Shared storage for EVE Frontier storage units: your own storage, the tribe's, and a vault for the trusted, kept in one unit.

- **Your storage**: your own slot in the unit.
- **Tribe storage**: the unit's open inventory, open to the tribe the owner sets up.
- **Auditor vault**: the unit's main inventory, shown only to the auditors the owner names (and the owner).
- Contract: `0x9751052bb88110c3b1212e5cc15fcb463b3da7bfb19f0cc6a898b33379da05b3` (latest `0x7a5a899c25927aba5a4266c2d7ec6acc91febf963b27892433ff059801a5e8db`), testnet Stillness.

This repo is the built site (GitHub Pages, main root).
